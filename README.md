# Task 2: Phishing Email Analysis

Analyzed a sample phishing email to identify classic indicators of phishing:  
- Suspicious sender address and domain spoofing  
- Suspicious URLs with mismatched link text and actual links  
- Urgent and threatening language coercing immediate action  
- Absence of attachments but typical phishing phrasing  
- General report outlines risks and advises caution
